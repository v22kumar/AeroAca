# AeroAca

A mobile-first engineering learning academy for Sushmita.

**Learner career title:** Associate Avionics Engineer  
**Core direction:** Electronics R&D, embedded systems, hardware/firmware integration, product development, debugging, and engineering interviews.  
**Industry reach:** Aerospace, automotive, medical devices, industrial electronics, consumer electronics, and semiconductors.

## Goals

- Begin job applications and interview practice immediately while learning in parallel.
- Build a practical 30-day interview fast track with sustained 90–180-day technical development.
- Make learning interesting through short visual lessons, realistic engineering missions, interactive quizzes, hands-on exercises, and spaced revision.
- Preserve factual distinctions between prior professional experience, new coursework and portfolio projects.
- Keep all learning content extendable and reviewable, grounded in real job descriptions and authoritative engineering references.

## Planned delivery

- **Frontend:** Mobile-first Next.js + TypeScript + Tailwind CSS.
- **Content:** Markdown/MDX chapters, exercises and question banks.
- **Deployment target:** Vercel, with installable PWA support.
- **Learning UX:** Today's mission, concise visual lesson, engineering challenge, instant feedback, interview practice, and progress tracking.
- **Progress:** Local storage initially; authenticated, cross-device sync later.
- **Privacy:** Repository is currently **public**. Never commit proprietary employer information, real interview credentials or secrets. A public repository is not a private deployed app.
